Your Objective

Your goal is to analyze the binary and identify the specific input required to trigger a "Congratulations" or "Success!" message.

Once you have found the solution, click the "Submit Solution" button located in the top-right corner of the interface.

Test Structure
  • Warmup: This challenge is optional. Use it to familiarize yourself with the tool's interface and features.
  • Core Challenges: The remaining two challenges are the main part of the experiment. We recommend solving them in a single, uninterrupted session.
Submission Format

For Test 1 and Test 2, a strict flag format is not required. You may simply provide:

  • A brief description (1-2 lines) of the solution.
  • The command line arguments that cause the function to print the success message.

Access additional views using the tabs at the top of the workspace:

  • Strings: View strings and their cross-references (xrefs).
  • Callgraph: Visual representation of function calls.
  • Functions List: View xrefs (to and from) for any selected function.
